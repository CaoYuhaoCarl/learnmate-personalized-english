# 教师 Web 页面验收

范围：老师上传作业、对照原图编辑 AI 草稿、确认定稿并获取对应版本的报告。
本次未实现学生账号、长期画像或自动交付学生。

## 老师独立试用

按 README 配置并启动应用，打开首页并登录。
先使用 [合成语法作业](../tests/fixtures/web_grammar.png)，其中姓名 Demo Learner 为虚构标识，不含真实学生数据。
提交会调用配置的 Google 模型。

1. 选择图片并提交，确认页面显示处理状态，不能重复点击提交。
2. 刷新页面，确认仍是同一次提交，且只出现一次记录。
3. 对照图片核验两题：`She go` 应改为 `She goes`，`They plays` 应改为 `They play`。
4. 修改一条解释，保存草稿并刷新，确认修改保留；检查 AI 原稿仍显示初始结果。
5. 勾选已核对本批作业，再点击“确认并生成 PDF”，打开并下载报告，核对修改与版本一致。
6. 再次修改解释并保存，确认显示新草稿、旧 PDF 被标为历史定稿；重新确认后，新旧版本分别可查。
7. 开始新作业，再从最近提交或历史 PDF 页找回此前结果。

作文评分另用一份不含真实学生信息的合成作文试用，原文、题目和预期改动由老师事先记录。
修正识别文字、删除一条误判或补充一条漏判，检查相关练习重点随错误列表更新。
调整四项维度分（每项 0 至 5 分，支持 0.5 分步进），核对页面总分为四项之和，并确认保存后系统建议没有覆盖教师分。
检查确认后的页面和 PDF 是否忠实保留这些修改，旧定稿是否仍显示旧内容。

老师无需开发者指导完成以上流程后，记录卡住的步骤、是否能辨认失败及下一步，以及反馈是否便于核对。
教师独立试用和教学内容认可仍待实际使用者完成；软件验证不能替代教学效果评估。

## 已明确的限制

本地单老师、单 worker 运行，作业状态落盘，但不提供跨服务器任务队列或自动恢复执行。
模型分析在输入范围内重试沿用原工作流设置；页面不会自动重新提交整个批次。
PDF 导出失败时教师定稿仍保留，可在页面单独重试导出，无需重新调用模型；每次尝试使用独立目录，成功的报告不会因其他报告失败而丢失。
同名学生身份区分仍需老师分批提交并核对，界面不声称实现了稳定学生身份。
HEIC/HEIF 接收边界经过测试，真实模型冒烟使用 PNG；不同拍摄设备的 HEIC 解码仍需实际样本验证。
